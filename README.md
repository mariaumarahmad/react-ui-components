# React UI Components

A small, reusable React component library built with **React + TypeScript + Vite**.

Built as a portfolio project to demonstrate component architecture, accessibility, and clean TypeScript patterns.

## ✨ Components

| Component | Description | Status |
|---|---|---|
| `Button` | Variants (primary, secondary, outline), sizes, loading state | 🚧 In progress |
| `Card` | Image, title, description, footer slot | 🚧 In progress |
| `Modal` | Accessible dialog with ESC close and backdrop click | 🚧 In progress |

## 🛠️ Tech Stack

- **React 18** — Component library
- **TypeScript** — Type safety
- **Vite** — Fast dev server and build
- **CSS Modules** — Scoped styling

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/mariaumarahmad/react-ui-components.git
cd react-ui-components

# Install dependencies
npm install

# Run the dev server
npm run dev
